# Words that are SAFE but set a grown-up scene. Applied only to example sentences.
#
# Separate from blocklist.txt because the two answer different questions.
#
#   blocklist.txt        never anywhere. `casualty` means dead people; there is no question
#                        type in which it belongs.
#   this file            fine as a word, wrong as a setting. `market`, `court`, `president`,
#                        `report` are all words an eight-year-old knows. But a SENTENCE is a
#                        little scene, and these build one out of the news: "received
#                        confirmed reports of casualties", "the tax cut will boost the
#                        economy", "he criticized the awarding of compensation by the court".
#
# The distinction matters because the first list, applied to everything, would take `court`
# and `bank` and `office` out of the vocabulary entirely, and they are ordinary words a child
# should be asked about. It is only when they are strung into a sentence that they stop being
# vocabulary and start being the six o'clock news.
#
# Why a list and not a rule: frequency cannot see topic — `casualties` is common enough to
# pass any readability bar. Concreteness cannot either; it was tried, and it threw out "Adjust
# your eyes to the darkness" while keeping "he acted as a caretaker until a new president
# could be elected", because `president` is a concrete noun and `darkness` is not.
#
# Matching is whole-word with the simple inflections, as in blocklist.txt.
